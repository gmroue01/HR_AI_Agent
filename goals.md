The goal of this project is to benchmark four frameworks of LLM evaluation/testing.
Why ? To understand proprely, how a test team can test and monitoring AI agent.

The frameworks chosen are : 

- DeepEval
- TrueLens
- Opik
- Promptfoo

To do so, i built a little use-case HR agent, which its features are described in the [`FEATURES.md`](./docs/FEATURES.md).

The deliverable is a full documentation of use-case, the how-to-use tools and about the method of testing and benchmarking.

The benchmark takes in account these aspects:

- Agent answer (EU-AI-ACT)
- Rag system (hallucination, rag triad)
- tool calling (how agent can call function to get data faithfully)
